01 / PLUGIN

Live keys, dials and strips.

The Prism Display action plays any facet on any key or dial, animated, with states, presses and turns. It is visual; it can also open a web page or switch profile when pressed. Prism Info Bar lights the Neo. The sample profiles put Stream Deck’s own media, volume and hotkey actions in Prism art on their Home page, and simulated data is tagged DEMO on the device.

  1. Download the plugin.
  2. Double-click it and confirm in the Stream Deck app.
  3. Drag Prism Display from the Prism Deck category onto a key, then pick a facet.

LINUX

No vendor app? No problem.

OpenDeck runs the same plugin unchanged: install it from OpenDeck’s Plugins tab with Install from file. Keys, spans, dials, the strip and the Neo info bar all work. StreamController takes the icon packs: rename a .streamDeckIconPack to .zip and import it as a custom pack.

OR FROM THE REPOSITORY
# Node.js 20+, nothing to install
git clone https://github.com/crazy54/Prism.git
cd Prism/prism-deck
node cli.js devices

04 / FOR AGENTS

A third island.
Every key.

The deck catalog ships as #prism-deck-catalog in Prism.html, next to the web and terminal islands. Each record carries its gallery, surface, states, press behavior, device targets and ready-to-use plugin and code snippets, and the island holds every module, so it renders fully offline.

IN THE PAGE, OR IN PRISM.HTML
const deck = JSON.parse(
  document.getElementById('prism-deck-catalog').textContent);

deck.facets
  .filter((f) => f.surface === 'key' && f.states.length)
  .map((f) => f.usage.plugin);
// → ['Stream Deck app → Prism Deck → "Prism Display" → Mic', …]
