Prism Display changes only this key's picture. It doesn't play music, change the volume or send keys. For those, use a Stream Deck action (Multimedia, Hotkey, Website, Open) and give it an icon from a Prism icon pack: the Prism sample profiles are built that way.

Parameters

Plugin settings
Default mode
Motion

Key and dial updates per second the plugin sends to the Stream Deck app, shared by all devices (default 200, at most 250: the app falls behind above about 250). Lower it if keys lag.

Image format

SVG is sharpest and smallest. Switch to PNG if a device draws some art wrongly.

Off by default. When on, the Prism power-on sequence (about 15 s) plays across your keys each time the plugin starts. Press any key to skip it; Still motion skips it too.

Data sources

Keys that show data say where it comes from. Anything simulated wears a small DEMO tag on the device.

The full path of a local .ics file. Outlook, Google Calendar and Apple Calendar can export or sync one. Prism reads only the event titles and times, every 60 s, and nothing leaves your computer. Leave it empty for the demo day.

Lets an AI assistant you connect (through Prism's MCP server) change how Prism keys and dials look. It never runs programs, presses keys or opens links. Off by default; each assistant must be approved by pressing a glowing Prism key on your deck. Switching this off removes every AI edit.
