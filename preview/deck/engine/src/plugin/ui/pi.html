Game Link

Counter-Strike 2 can send your own game state (health, ammo, money, the round) to Game Link keys through Valve's Game State Integration, and local companions such as Prism Control's Prism Sight can send theirs. It only reads: nothing is ever sent to a game, and nothing leaves your computer.

Off by default: no port is open. On, Prism Deck listens on this computer only (127.0.0.1), for CS2 and for companions. Connect CS2 turns it on for you.

Connect CS2 adds one file, gamestate_integration_prism.cfg, to your CS2 cfg folder and never touches other apps' files. Restart CS2 afterwards. Disconnect removes it. Change the port only if another app already uses it, then click Connect CS2 again.

Connect Dota 2 adds one file, gamestate_integration_prism.cfg, to Dota 2's cfg/gamestate_integration folder (and makes that folder if needed). Dota 2 also needs the launch option -gamestateintegration: in Steam, right-click Dota 2 → Properties → General → Launch Options, add it, then restart Dota 2. Prism never changes Steam's settings for you. Your own hero only: never anything about other players that the game doesn't show you.

Reads your own match from the game client's local Live Client Data API (127.0.0.1:2999, Riot's certificate checked) while a match runs. Off by default; turning it on also turns listening on. Ability cooldowns aren't reported by the game, so Prism never shows or guesses them.
