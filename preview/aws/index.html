HOW IT WORKS

Three ways a key acts. And a list it never touches.

The packs put every AWS action in one of these tiers, and the tests check every binding against them.

PRESS

Safe keys run on press

Service jumps, tabs, scrolling, the Region dial's browsing and the AWS key itself. They change pages, never your account.

HOLD 0.7 S

Read-only commands run at the end of a hold

WHOAMI, S3 LS, EC2 LS, LOGS LS and the month's cost type the command and press Enter only when you hold the key for 0.7 seconds. A tap does nothing. On a Galleon dial: push to arm, push again.

TYPED, YOU PRESS ENTER

Anything that changes resources waits for you

EC2 START and STOP, S3 COPY, ECS REDEPLOY and SSO LOGOUT are typed and left on the line for you to finish. So are the PROFILE, REGION and LOG GROUP dials: they type the line and stop.

NEVER

Not bound, by design

No secrets are typed. Nothing reads or writes ~/.aws/credentials. aws configure key entry has no key. Text only ever goes to the window you pressed in: if another window comes to the front, the rest isn't typed.

THE AWS MODULE

Your config, your aws.exe, three read-only calls.

Profiles
Only the [profile …] and [default] headers of your ~/.aws/config (or AWS_CONFIG_FILE), watched for changes. Names outside a strict character set are refused. Never logged.
Calls
Your own aws.exe, started with an argument list: no shell, --output json --no-cli-pager, a timeout, nothing piped in. Each call follows a press; nothing runs on a timer.
ACCOUNT
sts get-caller-identity shows the account as •••• 0000: the last four digits and the kind (ROLE, USER, ROOT). The full id never reaches the deck.
LOAD LOGS
logs describe-log-groups, the first 200 names, for the deck's profile and Region. The LOG GROUP dial's push types aws logs tail '…' --follow --since 15m.
MONTH $
ce get-cost-and-usage on its own key only. AWS charges $0.01 per Cost Explorer request, so a second press within a minute reuses the answer.
SSO
An expired session says SSO LOGIN NEEDED on the deck; the SSO LOGIN key types aws sso login for you to run.
Streamer-safe
Profiles become PROFILE 1, 2, 3, log groups LOG GROUP n, and the account and the cost leave the deck. Try the switch above the demo.

STATUS

Built, and what's next.

BUILT

  • The AWS context packs: the AWS Management Console (through the Prism browser extension), the AWS CLI in Windows Terminal with PowerShell, cmd and bash/zsh syntax, and the VS Code terminal.
  • The AWS module in Prism Control: profiles, Regions, log groups, the masked account and the month's cost, tested against a fake aws.exe and a made-up config.
  • Layouts for the Galleon 100 SD, Stream Deck + and Stream Deck XL. Every deck frame on this page is the engine's own render.

NEXT

  • The first live check is yours: your aws.exe, your config, your SSO session.
  • The module joins the Prism Control plugin in the next integration wave. Until then its dials say they need it.
  • Switching the console's Region from the deck needs the browser module (planned): AWS documents no keyboard shortcut for it.
  • In VS Code, the terminal page needs the ${focusedView} window title setting.
