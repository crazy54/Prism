  Prism Night and Prism Day as color schemes for your terminal. Each file is    
  plain text with its install notes at the top: read it, then install it        
  yourself. Nothing here changes your settings.                                 
                                                                                
ANY TERMINAL, THIS SESSION · ALSO OVER SSH ──────                               
  curl -sL prism.jeremyfhall.com/themes/osc/prism-night.sh | sh                 
  curl -sL prism.jeremyfhall.com/themes/osc/prism-day.sh | sh                   
  One printf of OSC 4 / 10 / 11 codes: on a remote host the codes travel back to
  your own terminal. It lasts until the terminal closes.                        
                                                                                
FILES ───────────────────────────────────────────                               
▌ Windows Terminal                                                              
   curl -sLO prism.jeremyfhall.com/themes/windows-terminal/prism-night.json     
   curl -sLO prism.jeremyfhall.com/themes/windows-terminal/prism-day.json       
   paste the object into "schemes" in settings.json, then pick it under Profiles
   → Appearance → Color scheme                                                  
▌ iTerm2                                                                        
   curl -sLO prism.jeremyfhall.com/themes/iterm2/prism-night.itermcolors        
   curl -sLO prism.jeremyfhall.com/themes/iterm2/prism-day.itermcolors          
   Settings → Profiles → Colors → Color Presets… → Import…
