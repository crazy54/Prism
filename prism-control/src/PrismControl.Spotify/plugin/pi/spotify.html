Setup and help

Setup Create a free app at the Spotify developer dashboard (Web API only) with the Redirect URI http://127.0.0.1:43117/callback (127.0.0.1, not localhost). Copy its Client ID here. Don't paste the client secret: Prism Control doesn't use it.
Trouble? "INVALID_CLIENT: Invalid redirect URI" means the Redirect URI in your Spotify app doesn't match exactly. "INVALID_CLIENT: Invalid client" means the Client ID was pasted wrong. Spotify asks you to sign in again every 6 months; the keys then show Reconnect.

Playback

Equalizer Spotify's in-app equalizer has no API, so no app can change it. Use the Prism Control EQ actions (SteelSeries Sonar or Equalizer APO) instead.
