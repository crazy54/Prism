Privacy

Private shows states, times and tool kinds only. Reveal adds session names, workspace folder names and the scrubbed command, file path or URL of a request (Approve locks when it can't be shown in full). Prompts and replies are never shown. The ON AIR key always forces Private. Approve works only in Reveal, because you must see what you approve.

Approvals

No request waits on the deck while Windows is locked, or when nobody touched the PC or a deck key for this long (set it to your Stream Deck sleep time; 0 = never by idle time): the agent's own prompt appears at once.

Prism hooks

Hooks give instant states and deck approvals for Claude Code and Codex. Without them the fleet board still works from claude agents --json, Codex logs and the process list.
