      Streamer-safe

      Prism Control downloads that artwork itself, from this PC, not through the browser. If Windows has a proxy for the site, it skips it rather than bypass the proxy.
      Hidden titles never leave the browser: the extension filters them before anything reaches Prism Control. Without the extension, media keys show what Windows' media controls show, never more than your strictest browser profile allows.

      Keys Prism Control presses

      Windows only lets an app take the front after a real key press, and the browser only opens picture-in-picture after one. So Prism Control presses a key nobody types: F24 for picture-in-picture, F22 to bring a window to the front. These are global keystrokes: an app with a hotkey on the same key (OBS, Discord, AutoHotkey and others use F13–F24) may react. Prism Control checks first and never presses a key another app registered as a hotkey (the key then says "F24 IN USE"), but hotkeys made with keyboard hooks can't be detected. If something reacts, pick another key here, or turn the focus trick off: the browser then asks Windows itself, and its taskbar button flashes instead of coming to the front.
