One spectrum. Every hue earns its place.

The website's violet → periwinkle → mint gradient, extended into a full spectrum by walking OKLCH hue in even steps from the accent (h 296°) to rose (h 8°). Three tiers per mode: ink for text and strokes, vivid for beams, glows and marks, wash for tints. λ is the real dominant wavelength of each color (CIE 1931); purples carry a c for complementary.

Do · identity

One hue per context. A gallery's hue marks its index, eyebrow, active state and focus glow — and nothing else on the page competes with it.

Do · state

Status colors are spectrum positions too (info azure, pos mint, warn citrine, neg coral, crit magenta). Pair them with a shape or a word — never color alone.

Don't · wallpaper

No rainbow fills, no multi-hue buttons, no spectrum behind body text. The full ramp appears only where the spectrum is the subject: the ruler, the Spectrums gallery index, First Light.

Every gallery owns a wavelength.

Galleries take even steps along the ramp in navigation order, so the sidebar reads as one continuous spectrum, top to bottom. App pages are white light — unrefracted — and wear CIE illuminant codes. The three surfaces sit far apart: Web violet, Terminal phosphor mint, Stream Deck lit-key amber.

Inter, tight. Mono, wide.

Inter is bundled in Prism.html at 400, 600 and 700 (Latin subsets, design/fonts/). Display sizes track tight and negative; instrument labels are system mono, uppercase, tracked wide. No web fonts, no CDNs.

Depth from light, not shadow.

Surfaces read as cut glass: a hairline border, a one-pixel highlight on the lit top edge, soft radius. Each elevation adds light to the edge and a little lift to the fill; only overlays cast a real shadow. Day replaces emitted light with reflected light — tinted soft shade and a thin-film sheen.

Things arrive by converging.

Motion is refraction: a slight chromatic split that resolves into focus, eased out exponentially. Arrivals 240–600 ms, exits faster, nothing blocks input. Every pattern has a reduced-motion form: a 120 ms fade, or nothing.

Thinking, made visible.

Prism in sixteen colors.

prism-term ships a Night and a Day palette. Magenta is the Prism violet so prompts and highlights carry the brand; bright black is a legible dim (≥4.5:1). Truecolor uses the spectrum directly; 256-color maps by OKLab distance; 16-color uses only the semantic slots.

Depth

Detect, never guess

NO_COLOR → none · COLORTERM=truecolor → 24-bit · TERM=*256color* → 256 · else 16. Gradients interpolate in OKLCH.

Mode

Night unless the terminal is light

Query OSC 11 with a 100 ms timeout, else COLORFGBG; background lightness above 0.6 → Day palette.

Quantize

Spectrum in 24-bit vs 256

Top: the 12 stops in truecolor. Bottom: the designed xterm-256 index for each — the nearest that keeps 4.5:1 as text on every 256-color surface (tokens.json → terminal.*.spectrum256).

Keys you can read from across the desk.

Author every key at 144 × 144 and downsample to 72. One value, one label, one hue index; everything essential inside the 12 px safe area, text inside 16 px. States are light, not decoration: off is quiet glass, on lights the edge in the gallery hue, alert adds a corner notch, busy sends a beam around the rim.

Beautiful is not an excuse.

WCAG 2.2 AA in both modes: text 4.5:1, controls and focus 3:1, visible focus everywhere, full keyboard reach, reduced motion honored, and no meaning carried by color alone.

Focus

A beam, never removed

2 px --rf-focus outline, 2 px offset, 6 px halo. ≥7:1 against every surface in both modes. Inputs move the ring onto the baseline.

Motion

Fade or nothing

prefers-reduced-motion turns every pattern into a 120 ms fade, stops loops, skips First Light and the relight sweep. [data-rf-motion="reduce"] forces it in-app.

Color is never alone

Shape + word + hue

Selected chips gain a dot; alerts gain a corner notch; status toasts carry a title. The spectral index is a reinforcement of the label, never a replacement.

Keyboard

Everything reachable

Skip link, roving focus in nav and chips, Ctrl/⌘ K for the palette, Esc closes overlays, ↵ opens, arrow keys move. First Light is skippable by any key and never blocks input.

Showcased content

Chrome only

Facets that demonstrate other design languages render as authored. Refraction restyles only chrome: tile scaffolding, filters, headers — never .panel / .card.
