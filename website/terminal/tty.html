BROWSE FROM YOUR TERMINAL·λ 514

The catalog, in
your terminal.

Every gallery and every facet is a plain ANSI page you read with curl — no install, no account, no JavaScript. When you want it moving, one npx command plays any facet live, at your terminal's real size and color depth.

Start here
$ curl -sL https://prism.jeremyfhall.com/tty

On Windows PowerShell 5.1? Turn on Windows — plain curl is an alias there and fails.

Back to the terminal catalog

01 / FOUR COMMANDS

From home page to live player.

Pages are stills that fit 80 columns and use only color and text — no cursor tricks — so they work over SSH, in tmux, in a CI log, anywhere.

01

Open the terminal home

Every gallery with its facet count, and the commands to go deeper.

Home
$ curl -sL https://prism.jeremyfhall.com/tty
02

Open a gallery

One page per gallery, sorted by category. /t/help explains everything; /t/all lists every facet on one line each.

Gallery
$ curl -sL https://prism.jeremyfhall.com/t/loaders
03

Open one facet

A still frame, what it needs (glyphs, colors, size), its parameters, and the exact command that plays it.

Facet
$ curl -sL https://prism.jeremyfhall.com/f/plasma
04

Play it live

The live player animates in real time and detects your terminal: truecolor to mono, braille and blocks or plain ASCII. Node.js 18+, nothing installed globally.

Live · Node 18+
$ npx -y --package=https://prism.jeremyfhall.com/dl/prism-term.tgz prism-term play plasma

Drop play plasma to open the catalog browser: arrows to move, / to search, Enter to play, q to quit.

03 / GOOD TO KNOW

Made for real terminals.

VARIANTS

Plain text and truecolor

Every page also comes as .txt — 7-bit ASCII with no escape codes, for grep, NO_COLOR, LANG=C, serial consoles and screen readers — and as .24 for 24-bit color instead of the default 256.

LONG PAGES

Page, search, save

curl -sL prism.jeremyfhall.com/t/all | less -Rcurl -sL prism.jeremyfhall.com/t/all.txt | grep -i spinnercurl -sL prism.jeremyfhall.com/f/plasma -o plasma.ans

REQUIREMENTS

What you need

  • Any curl — macOS, Windows 10+ and most Linux distributions ship one. On Windows, type curl.exe (or turn on Windows above).
  • Color pages: any 256-color terminal. .txt: anything at all.
  • Live player: Node.js 18+. Prefer a permanent install? npm i -g https://prism.jeremyfhall.com/dl/prism-term.tgz

Rather click than type? Every facet is live in the browser.
