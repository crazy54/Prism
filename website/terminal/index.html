02 / IN YOUR TERMINAL

Nothing to install.
Just a terminal.

Read the whole terminal site with curl — every gallery and every facet is a plain ANSI page, with .txt variants for 7-bit terminals and screen readers. When you want it moving, one npx command plays any facet live, at your terminal's real size and color depth.

Terminal directions →
Browse with curl
$ curl -sL https://prism.jeremyfhall.com/tty

Windows PowerShell: curl.exe -sL … · page through with | less -R

Play live · Node 18+
$ npx -y --package=https://prism.jeremyfhall.com/dl/prism-term.tgz prism-term

Opens the catalog browser: arrows to move, Enter to play, q to quit.

Use it in code
import { play, findFacet } from 'prism-term';
await play(findFacet('plasma'));

03 / FOR AGENTS

One JSON island.
Every facet.

The terminal catalog ships as a second JSON island, #prism-terminal-catalog, in Prism.html — the same _ai convention as the web catalog — with a lean copy (everything but source and preview) in this page. Each record carries its gallery, tags, size, glyph and color needs, parameters and ready-to-run commands.

terminal-catalog.json ↓
// In the page, or in Prism.html
const catalog = JSON.parse(
  document.getElementById('prism-terminal-catalog').textContent);

catalog.facets
  .filter((f) => f.gallery === 'loaders' && f.glyphs === 'ascii')
  .map((f) => f.usage.cli);
// → ['prism-term play loaders-line', …]
