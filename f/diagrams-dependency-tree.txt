Dependency Tree  diagrams-dependency-tree
An npm ls --all tree printing line by line with deduped markers, then npm audit
lights the path from the root to a vulnerable transitive dependency.
diagram - 60x20 (min 44x10) - 8 s loop - unicode - 16 colors
tags: dependencies, npm ls, tree, supply chain, vulnerability
