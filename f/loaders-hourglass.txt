Hourglass  loaders-hourglass
An hourglass flipping between running and empty -- the universal "this will take
a while".
spinner - 44x5 (min 24x2) - 8 s loop - unicode - 16 colors
tags: spinner, loader, emoji, hourglass, wait

                   | Queued behind 3 jobs...             4.0s

                   - \ | /

                   hourglass (ASCII fallback) - 4 frames - 1.
  still at t=4s -- run it live to see it move

Params  (--set key=value)
  speed=1               Speed  (0.25-4)

Run it live  (Node 18+, no install)
  npx -y --package=https://prism.jeremyfhall.com/dl/prism-term.tgz \
    prism-term play loaders-hourglass
Snapshot  prism-term snapshot loaders-hourglass --size 44x5
In code
  import { play, findFacet } from 'prism-term';
