* PRISM TERMINAL > Architecture Diagrams > Boxes & Flows
Flowchart  diagrams-flowchart
A delivery flowchart with decisions, labeled yes/no branches and a fix loop; a
run token walks it, fails tests once, loops back, then ships via a canary.
diagram - 64x17 (min 62x17) - 9 s loop - unicode - 16 colors
tags: flowchart, decision, process, ci, graph

                             +--------------- fix ---------------+
                             v                                   |
        +---------+      +-------+      +----------+  no    +--------+
        | commit  |----->| build |----->| x tests? |------->| notify |
        +---------+      +-------+      +----------+        +--------+
                                              |
                                              |yes
                                              v
        +-------+ yes +-----------+     +-----------+
        | ship  |<----| healthy?  |<----| canary 5% |
        +-------+     +-----------+     +-----------+
                            |no
                            v
                      +-----------+
                      | roll back |
                      +-----------+
        x unit tests failed . author notified
  still at t=4.5s -- run it live to see it move

Run it live  (Node 18+, no install)

    prism-term play diagrams-flowchart
