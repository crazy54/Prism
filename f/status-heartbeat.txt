* PRISM TERMINAL > Notifications & Status > Health & Uptime
Heartbeat Monitor  status-heartbeat
A cron and worker heartbeat monitor drawn as an ECG trace: each check-in is a
beat, missed beats flatline red and raise the alarm.
widget - 72x9 (min 30x4) - 24 s loop - unicode - truecolor
tags: heartbeat, ecg, monitor, dead man switch, braille

    billing-worker  ALIVE                    every 0.8s - last beat 0.1s ago
                                                                           @
                           =                                               *
                           =                                               *
        -                 = =                           +                 *
    ---- --------  ======== ========= ========++++++++++ ++++++++  +++++++*
                 --                  =                           ++

    15/15 check-ins in the last 12 s - 0 missed - alert after 2
  still at t=6s -- run it live to see it move

Run it live  (Node 18+, no install)
  npx -y --package=https://prism.jeremyfhall.com/dl/prism-term.tgz \
    prism-term play status-heartbeat
Snapshot  prism-term snapshot status-heartbeat --size 72x9
In code
  import { play, findFacet } from 'prism-term';
  await play(findFacet('status-heartbeat'));
