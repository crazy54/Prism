Shell Autocomplete  input-autocomplete
A shell prompt with a fish-style ghost suggestion from history, a zsh-style
completion menu that Tab cycles, then -> accepts and the command runs.
tui - 64x12 (min 40x8) - 8 s loop - unicode - 16 colors
tags: autocomplete, completion, shell, zsh, fish
